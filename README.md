# 📥 YouTube Downloader App

A simple and clean app that helps you download YouTube videos in different qualities. Just paste the link, choose the resolution, and save your favorite videos directly to your device.

---

## 🚀 Features

- Paste a YouTube video link to extract video info
- Choose from available video resolutions
- Download videos easily with one tap
- See your download history
- Smooth and responsive UI for Android devices

---

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sumit-9900/video_downloader.git

   ```

2. Navigate to the project folder:

   ```bash
   cd video_downloader

   ```

3. Install the dependencies:

   ```bash
   flutter pub get

   ```

4. Run the app:
   ```bash
   flutter run
   ```

---

## 🧠 How It Works

- The app fetches the video details using the video link.

- It shows you a list of available video resolutions.

- You select the resolution, and the app downloads the video for offline viewing.

## 📦 Tech Stack

- Flutter (cross-platform app)

- YouTube Explode Dart (video extraction)

- Bloc & Cubit (state management)

- Dio (downloading videos)

## ✅ Conclusion

This app makes downloading YouTube videos easy and user-friendly. It's a great tool for anyone who wants to save videos for offline viewing. Simple, fast, and effective.
